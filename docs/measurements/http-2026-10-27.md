## Dokoncene lokalne overenie

Vystupy su v `results/http-local-validation-20261027-225404-f_4imyes/`:

- 23 testov `python3 -m unittest discover -s tests -v` preslo mimo sandboxu.
  HTTP aplikacia bola testovana na loopbacku. Zivotny cyklus serie pouzival
  simulovane zavislosti: uspech, chyba HTTP, chyba zataze a prerusenie.
- Overene boli percentily, CPU rozdiely, odmietnutie roztrhnutych intervalov,
  pomaleho riadiaceho spojenia a nemozneho casovania, zachovanie ciastocnych
  dat a obnova docasnej trasy pri chybe.
- Skutocny izolovany iperf3 3.21 bezal na loopbacku, jeden tok TCP,
  ciel 50 Mbit/s, 4 s v kazdom smere. Prijimac dosiahol priblizne
  50.000 a 50.053 Mbit/s. Surove JSON, stderr, prikazy a casovanie klienta
  zostali ulozene. Algoritmus prekryvu bol overeny syntetickou casovou sondou.

Stav `passed_local_validation` znamena iba lokalne overenie. Tieto vysledky
nie su prenosom cez UE TUN, HTTP seriou v 5G labe ani meranim MEC.
V sandboxe test HTTP servera skoncil pri vytvarani socketu chybou
`PermissionError: [Errno 1] Operation not permitted`; mimo sandboxu presiel.

## Nasledujuce meranie na VM s opravneniami

Z korena projektu v terminali s pristupom k Docker a root namespace:

```bash
sudo python3 scripts/check-edge.py
sudo python3 scripts/measure-http.py
```

Ak pilot zlyha, najprv oddelit ping UE -> UPF od kontroly UPF -> edge
`/health` a ulozit diagnostiku. `compose-up.sh` pouzit iba pri potvrdenej
poruche UE a mimo merania; obnovuje gNB a UE. Nespustat reset ucastnika,
MongoDB ani nove zostavovanie obrazov.

Plan serie: idle, TCP UL a TCP DL; tri opakovania kazdej skupiny,
20 HTTP poziadaviek na opakovanie, interval zaciatkov 0.4 s, zataz 16 s
s cielom 50 Mbit/s. Spolu 180 planovanych poziadaviek. Kazda odpoved
musi potvrdit obsah, request_id, adresu UE a NAT zdroj UPF. Prekryv sa
overuje konzervativnym oknom z monotonneho zivota klienta a suvislych
nenulovych datovych intervalov. Cas HTTP nie je ciste sietove RTT.

Novy beh vytvori vlastny adresar `results/http-*` so surovymi datami,
CSV, `summary.json` a `report.md`. Az skutocne dokonceny a overeny beh
moze mat stav complete. TCP ciel 50 Mbit/s nepredstavuje maximalnu kapacitu.
